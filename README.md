# tomato-farm-maps

ミニトマトのハウス（施設栽培）向けの巡回記録アプリです。ハウスの俯瞰図（模式図）を表示し、気になる箇所をタップしてピンを立て、コメントを記録できます。スマートフォンでの利用を想定したPWA（ホーム画面に追加してオフラインでも利用可能）です。

## 対象ハウスのレイアウト

- メインハウス: 横幅25m × 縦幅(南北)80m
- ロックウールベッド 12列（1列目=西端、12列目=東端）、各列に表・裏の2ラインで合計24ライン
- 各列の中央（南北の中間地点）に養液の余剰を流す水路があり、水路を境に北エリア・南エリアに分かれる
- 支柱（表裏を繋ぐ門型）は北エリアに7本、南エリアに8本
- 事務所（10m×5m）はメインハウス南側に隣接。西端はメインハウスと揃っており、東面に外部からの入口、北面にハウスへの入口がある

これらの寸法・本数は `src/geometry/greenhouseConfig.ts` の `DEFAULT_GREENHOUSE_CONFIG` にまとめてあり、実測値が変わった場合はここを更新するだけで地図全体に反映されます。

## 主な機能

- ハウスの俯瞰図をSVGで表示（ピンチズーム・パン対応）
- 地図上の任意の場所をタップ → 最寄りの列・表裏・南北位置を自動判定してピンを仮置き
- コメントを入力して保存。既存ピンはタップして閲覧・編集・削除が可能
- ピンはブラウザのlocalStorageに保存（端末内保存、オフラインでも動作）
- JSON形式でのバックアップの書き出し・読み込み
